## 🚀 Featured Projects

### [Mersal — Bilingual RAG Document Q&A](https://github.com/AK17-dev/Mersal-Ai)
Ask questions about your PDFs in Arabic or English and get grounded answers with page-level citations. Built end-to-end on Cloudflare's edge stack. 🏆 Featured AI Showcase Project, Kanz AI Training Hackathon 2026.
- **Stack:** React · TypeScript · Hono Worker · R2 · Vectorize · D1 · Workers AI · Gemini
- **Highlights:** multilingual embeddings (bge-m3) with cross-language retrieval; LLM-as-judge eval pipeline scoring 20/20 on a bilingual suite, including hallucination-refusal cases; built within Workers CPU and rate limits
- 🔗 [Live Demo](https://mersal-117.pages.dev/)

### [Screenshot → Bug Report](https://github.com/AK17-dev/AI-Tool-Screenshot-to-bug-report)
My FlyRank capstone: upload a UI screenshot, get a file-ready bug report. Every field is tagged observed vs. inferred with a confidence level, so the model can't invent reproduction steps.
- **Stack:** Next.js 16 · TypeScript · Gemini structured output · Zod · Vitest · Playwright
- **Highlights:** Zod validation with a repair pass and per-field salvage; 152 tests at 78.9% coverage; 0 axe violations; Lighthouse mobile 96 performance / 100 accessibility
- 🔗 [Live Demo](https://ai-tool-screenshot-to-bug-report.vercel.app/)

### [EL "Easy" — Multi-Agent AI Concierge](https://github.com/AK17-dev/EL-EasyLife-AI-agents-Concierge-for-Life-Admin)
A personal concierge for life admin (tasks, scheduling, research, message drafting), built as my capstone for Kaggle's 5-Day AI Agents Intensive with Google.
- **Stack:** Google ADK · Gemini · Supabase MCP · Next.js
- **Highlights:** root ConciergeAgent routing to 5 specialist sub-agents, including a Planner-Critic DayPlanner; custom Supabase MCP server; security layer for prompt-injection blocking, PII redaction, and destructive-action confirmation

### [Funoun (فنون) — Artisan Marketplace](https://github.com/AK17-dev/FunounPlatform)
Multi-vendor marketplace for handmade artisan goods, built for the Arabic market.
- **Stack:** React 18 · TypeScript · Supabase (RLS, Auth) · PostgreSQL · Tailwind CSS
- **Highlights:** 4 user roles, product catalog, cart, custom orders, real-time order tracking, reviews, bilingual AR/EN UI
- 🔗 [Live Demo](https://funounplatform.netlify.app/)
